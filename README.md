# powerROC
An Interactive Web Tool for Sample Size Calculation in Assessing Models' Discriminative Abilities

## Overview
**powerROC** is a web-based tool designed to assist researchers in calculating the necessary sample size for evaluating the discriminative abilities of predictive models. This tool is particularly useful for those working in fields such as biostatistics, epidemiology, and machine learning applications.
